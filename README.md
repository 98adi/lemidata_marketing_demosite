# 📍 למידאטה (LemiData) — דף נחיתה אינטראקטיבי למציאת מקומות לימוד

> **דמו חי (Live Demo):** [https://98adi.github.io/lemidata_marketing_demosite/](https://98adi.github.io/lemidata_marketing_demosite/)

---

## 📖 על הפרויקט

**למידאטה (LemiData)** הוא דף נחיתה שיווקי וכלי אינטראקטיבי שנועד לפתור את אחת הבעיות הנפוצות והמתסכלות ביותר בחיי הסטודנטים בקמפוס: מציאת מקום לימוד שמתאים בדיוק לצורך הנוכחי[cite: 14]. 

בתי קפה וספריות נראים מצוין ברשתות החברתיות, אך בפועל סטודנטים מוצאים את עצמם מבזבזים זמן יקר בחיפושים ומגלים מוזיקה רועשת, מחסור חמור בשקעים או שולחנות צפופים מדי[cite: 14].

הפרויקט נבנה במסגרת **קורס שיווק**, ומשלב עקרונות של מחקר שוק, הגדרת הצעת ערך (Value Proposition), בניית משפך המרה (Conversion Funnel) ומיקוד במשתמש (Customer-Centric Design) — לצד פיתוח ממשק משתמש מודרני, מהיר ואינטראקטיבי[cite: 12, 14].

---

## 🎯 אסטרטגיה שיווקית ומוצרית

* **זיהוי כאבי הלקוח (Pain Points):**
  * **"קפה יש, שקט אין":** מוזיקה רועשת והסחות דעת כשהמטרה היא למידה אינטנסיבית[cite: 14].
  * **"אין שקעים כשצריך":** חרדת סוללה והצורך להיצמד לקירות במקום לשבת בנוחות[cite: 14].
  * **"אווירה לא מתאימה":** שולחנות קטנים מדי לעבודה עם לפטופ ומחברת או חוסר באווירת למידה תומכת[cite: 14].

* **הצעת הערך (Value Proposition):**
  * התאמה אישית מיידית לפי צרכים ספציפיים באותו רגע: שקט, שקעים, קפה, נוחות, אווירה ומפגש עם חברים[cite: 14].

* **עוגני המרה ומעורבות משתמש (Engagement Hooks):**
  * **שאלון התאמה דינמי (Interactive Quiz):** מאפשר למשתמש להגדיר מה חשוב לו ולקבל המלצה מדויקת באופן מיידי[cite: 12, 14].
  * **הוכחה חברתית (Social Proof):** רצועת ביקורות סטודנטים נעה (Marquee) המייצרת אמינות ותחושת קהילה[cite: 13, 14].
  * **מנגנון צמיחה קהילתי (Crowdsourcing Loop):** טופס המאפשר לסטודנטים להציע מקומות לימוד חדשים למאגר[cite: 12, 14].
  * **הנעה לפעולה רב-ערוצית:** חיבור ישיר לחשבון האינסטגרם של המותג (`@lemidata_`) וקידום הורדת האפליקציה[cite: 14].

## ✨ תכונות ופיתוח טכנולוגי

* **מנוע המלצות אינטראקטיבי:** סינון דינמי מבוסס צד-לקוח (Client-Side) המעדכן כרטיסי המלצה ומדדי דירוג מפורטים (שקט, נוחות, אוכל, אווירה ו-X-Factor) בליווי אנימציות מעבר חלקות[cite: 12, 14].
* **התאמה מלאה לעברית (RTL):** מבנה מותאם לכיווניות מימין לשמאל (`dir="rtl"`) וטיפוגרפיה נקייה באמצעות הפונט `Rubik`[cite: 13, 14].
* **ניווט חכם ומותאם למובייל:** סרגל עליון מטשטש וקבוע (Sticky Blur Header) ותפריט מגירה צידי למובייל (Drawer Sidebar) עם חסימת גלילה אחורית[cite: 12, 13, 14].
* **ביצועים גבוהים:** קוד נקי מבוסס Vanilla JavaScript ו-CSS3 טהור, ללא ספריות כבדות — מה שמבטיח זמני טעינה אפסיים ורינדור מיידי[cite: 12, 13].
* **הדמיית שליחת טפסים:** משוב ויזואלי מיידי בעת שליחת מקום חדש ללא צורך בריענון הדף[cite: 12, 14].

---

## 🛠️ טכנולוגיות

* **HTML5:** מבנה סמנטי, מותאם נגישות וכיווניות RTL[cite: 14].
* **CSS3:** שימוש ב-Flexbox, CSS Grid, משתני עיצוב (Custom Properties), אפקטי Glassmorphism ועיצוב רספונסיבי מלא[cite: 13].
* **JavaScript (ES6+):** מניפולציות DOM, ניהול אירועים ולוגיקת סינון בזמן אמת[cite: 12].
* **תחום אקדמי מוביל:** שיווק מוצר (Product Marketing), חוויית משתמש (UI/UX) ואסטרטגיית צמיחה (GTM).
